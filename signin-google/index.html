What this would actually do

Google hands us a verified email address and a name, and nothing else. No password ever reaches us, and there is no code to wait for in a mail client. Somebody whose address we already hold lands straight on their own profile. Somebody new gets an account made for them there and then, with their name already filled in.

What it needs from you, once

A sign-in client in Google Cloud Console, which only you can make, and its id pasted to me. It is a different thing from the one we abandoned this morning: it creates something new rather than changing what the live backend belongs to, and it can be deleted again with no trace.

What it does not change

The code by email keeps working exactly as it does now, for anybody without a Google account or anybody who would rather not use one. This is a second door, never a replacement.
