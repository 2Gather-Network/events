2 · Where others fail: Slack let anyone message anyone

The first message is a request

Nobody lands in your inbox uninvited. You see who, which group, and the message, then choose. Decline is quiet: the sender only sees "Not taking messages right now". Mute stops that person in every group, and you can unmute them in Settings. Messages from a host skip this step.

Maria Lopez from Snohomish County wants to message you

6 · On the group page, when the host turns Group chat on

Group chat

Members only. Quiet by default: no email per message, one optional daily summary. The host can pin a note at the top. Old messages load only when you scroll up, so opening the group page stays fast.
